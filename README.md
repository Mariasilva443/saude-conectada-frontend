# Saúde Conectada — Frontend

Frontend demonstrativo do projeto Saúde Conectada, baseado nas seis telas descritas no Projeto Integrador II:

1. Login
2. Dashboard
3. Agendamento
4. Cadastro de Paciente
5. Fila de Atendimento
6. Relatórios

## Tecnologia

- React
- Vite
- React Router
- Lucide React
- CSS responsivo

## Executar

Pré-requisito: Node.js 18+.

```bash
npm install
npm run dev
```

Depois, abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

## Build para entrega

```bash
npm run build
```

A pasta `dist/` será gerada.

## Observação

Esta versão é somente Frontend. Os dados exibidos são demonstrativos e os formulários simulam as operações para permitir a gravação do vídeo da segunda entrega.

O projeto foi preparado para futura integração com um Backend por API REST, conforme a orientação da entrega.

## Fluxo para o vídeo

Login → Dashboard → Agendamentos → Cadastro de Paciente → Fila de Atendimento → Relatórios.
